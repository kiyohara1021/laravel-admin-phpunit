# Security Policy / セキュリティポリシー

[English](#english) | [日本語](#日本語)

## English

Only the latest `main` branch is supported. Do not open a public issue for a suspected vulnerability. Use this repository's **Security → Report a vulnerability** flow and include impact, reproduction steps, and a suggested mitigation when available.

This is a learning sample, not a production-ready admin panel. Seeded passwords and local configuration must never be reused in production.

## 日本語

最新版の `main` ブランチだけをサポートします。脆弱性の疑いがある場合は公開Issueを作らず、このリポジトリの **Security → Report a vulnerability** から影響、再現手順、対策案を非公開で報告してください。

これは学習用サンプルで、本番向け管理画面ではありません。Seederのパスワードやローカル設定を本番で再利用しないでください。
