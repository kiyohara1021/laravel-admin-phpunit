# Code of Conduct / 行動規範

[English](#english) | [日本語](#日本語)

## English

Be respectful, specific, and constructive. Discuss the work rather than the person, protect private information, and accept maintainers' decisions about scope and moderation. Harassment, discrimination, threats, doxxing, sexualized content, and repeated disruption are not tolerated.

Report conduct concerns privately through the repository owner's GitHub profile. Maintainers may remove content or restrict participation to protect the community.

## 日本語

敬意を持ち、具体的で建設的に伝えてください。人ではなく成果物について議論し、個人情報を守り、範囲とモデレーションに関するメンテナーの判断を尊重してください。嫌がらせ、差別、脅迫、個人情報の暴露、性的な表現、継続的な妨害は認めません。

問題行為はリポジトリ所有者のGitHubプロフィールから非公開で報告してください。メンテナーはコミュニティを守るため、内容の削除や参加制限を行うことがあります。
